# Проверочные примеры восстановления

## artifacts.md — по изображению

Источник: `docs/_images/readme-example.png` закреплённого upstream md_design. Восстановлены три команды, три поля, выбор списка, регулирование числа и флажок. Навигация оболочки 1С (назад/вперёд/закрытие окна) не относится к содержимому формы и не добавлена. Коралловый цвет первой команды сохранён; ширина и рамка формы зависят от окна браузера и общей темы playground. Это известные отличия, не пиксельная копия.

## save-report.md — по XML EDT

Источник: `SettingsStorages/ХранилищеВариантовОтчетов/Forms/СохранениеВариантаОтчетаВФайл/Form.form` из предоставленной конфигурации Kafka. Сам XML не включён в пакет; пример не использует пути, модули или базу Kafka во время работы.

| Узел источника | Представление |
| --- | --- |
| ВариантыСохранения, ОдинВариантОтчета, НесколькоВариантовОтчетов | Две вкладки в исходном порядке |
| ИмяФайла, ИмяКаталога | Пустые поля выбора; реальные значения XML не задаёт |
| ПерсональныеНастройки + Пометка/Значение | Таблица с двумя колонками |
| ОписаниеВариантовОтчетов + Ссылка/ИмяФайлаКраткое | Таблица с двумя колонками только для просмотра |
| Сохранить | Основная команда |
| CheckAll / UncheckAll | Две команды с пояснительными подписями вместо платформенных иконок |

Заголовок выведен из имени формы: явного заголовка корня в XML нет. Надпись и группа персональных настроек сведены в один заголовок. Таблицы пусты: содержимое формируется при выполнении 1С и из XML неизвестно. Выбор файла/каталога демонстрирует ввод значения, не открывает системный файловый диалог. Автозаполнение команд, обработчики, расширенные подсказки, динамическая видимость и стандартные команды таблиц не исполняются.


## pricing-zones.md — по присланному пользователем скриншоту

Сохранены четыре поля, две команды, семь колонок и шесть зон в исходном порядке, значения границ, цветовые образцы и ограничения ячеек Z6/Z1. Цвета приближены по изображению. Числовые поля выровнены вправо по теме формы. Правила из подписи показаны текстом, автоматический пересчёт/ограничение процентов не исполняется. Состав строк и первые три колонки недоступны для изменения; значения и цвета меняются только в памяти страницы.
