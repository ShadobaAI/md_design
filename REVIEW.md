# Результаты ревью исходного playground

| Проблема исходного варианта | Исправление |
| --- | --- |
| Импорты работали только после ручного копирования в чужой checkout | Самостоятельный пакет, pinned upstream snapshot, lockfile, сборка и установщик |
| Непроверенный URL из query позволял выбирать источник, ошибки только в console | Один явно указанный локальный файл, loopback + случайный путь, Host/Origin checks, видимые ошибки |
| Группы, вкладки, флажки, меню и вложенные таблицы терялись | Рекурсивный renderer с вкладками, состояниями, вложенными заголовками и деревом строк |
| Разбор молча терял неизвестные символы; явные булевы свойства были строками | Проверка lexer и каждого parser group; кавычки сохраняются; bool нормализуется |
| Редактор, переключатели панелей, дерево CST, отладочный поиск Orama | Удалены из пользовательского интерфейса по требованию; осталась только форма |
| Тесты нельзя было запустить из раздела | Локальные unit/integration tests, CLI --check, изолированная установка |
| Зависимости исходного стека содержали известные уязвимости | Минимальный runtime, исправленные закреплённые зависимости; audit проверяется отдельно |

Подробные ограничения опубликованы в README и справочнике разметки. Это инструмент прототипирования, не эмулятор базы или обработчиков 1С.
