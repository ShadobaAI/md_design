/Поля и выборы
  ###Значения и типы
    Строка: Текстовое значение
    Пустое поле:
    Число: 12345.67 {Тип = Число(15, 2)}
    Дата: 18.09.2026__В
    Время: 14:30:00__В
    Дата и время: 18.09.2026 14:30:00__В
    Код с ведущими нулями: 000042 {Тип = Строка(6)}
    Составной тип: 100 {Тип = Строка(20), Число(15, 2), Булево}
  ###Кнопки поля ввода
    Выбор значения: Контрагент__В
    Выбор из списка: Основной__С
    Очистка: Удали это значение__Х
    Открытие: Карточка__О
    Регулирование: 5__Д
    Комбинация кнопок: Организация__ВСХО
  ###Многострочный ввод
    Комментарий: Несколько строк для описания
    ___________________________________
    ___________________________________
    ___________________________________
  ###Однострочная группа
    Номер: 000001 {Тип = Строка(6)} & от: 18.09.2026

    -> Надпись по центру <-
  ###Состояния полей
    Редактируемое: Можно изменить
    Только просмотр: Нельзя изменить {ТолькоПросмотр = Истина}
    Недоступное: Отключено {Доступность = Ложь}
    Скрытое поле: Не отображается {Видимость = Ложь}
    Без заголовка: Ввод без видимой подписи {ПоложениеЗаголовка = Нет}
