# Накидка для Codex — плагин прототипирования форм 1С

Плагин для Codex, использующий оригинальный проект [«Накидка» (md_design)](https://github.com/crimsongoldteam/md_design) в качестве программного ядра. Плагин обеспечивает создание и просмотр интерактивных макетов форм 1С по текстовому описанию, скриншоту или XML во встроенном браузере Codex.

> **Происхождение проекта и условия использования**
>
> Настоящий проект является самостоятельной разработкой плагина для Codex, использующей программные компоненты оригинального проекта [md_design](https://github.com/crimsongoldteam/md_design).
>

## Установка

1. Установи настольное приложение Codex со встроенным браузером.
2. Установи **Node.js 22 или новее** с [официального сайта](https://nodejs.org/en/download). Если не знаешь, установлен ли Node.js, попроси Codex проверить его версию. После установки перезапусти Codex.
3. В Codex открой **Плагины (Plugins)** → **Добавить (Add)** → **Добавить магазин (Add Marketplace)** → **Из репозитория (Add from a repository)**. Вставь адрес и нажми **Синхронизировать (Sync)**:

   ```text
   https://github.com/ShadobaAI/codex-plugins
   ```

4. В магазине **ShadobaAI** найди **Накидку**, нажми **Установить (Install)** и убедись, что плагин включён.
5. Начни новый чат в папке своего проекта и отправь:

   ```text
   Используй Накидку. Создай форму поступления: номер, дата,
   контрагент, склад и таблица с товаром, количеством и ценой.
   Открой форму во встроенном браузере.
   ```

При запросе доступа разреши запуск локального предпросмотра и открытие его страницы. Если доступ к странице заблокирован, проверь **Настройки → Браузер → Разрешения для сайтов (Settings → Browser → Agent permissions)** для указанного адреса. Организационные ограничения меняет администратор. Подробнее: [установка плагинов](https://learn.chatgpt.com/docs/plugins), [разрешения браузера](https://learn.chatgpt.com/docs/reference/settings#browser).

## Использование

Опиши форму обычными словами, приложи скриншот или XML. Изменения тоже можно задавать словами: «Добавь поле договора после контрагента». Для знакомства попроси: «Покажи пример showcase из Накидки».

Макет хранится в памяти предпросмотра. MD, HTML и скриншоты автоматически не создаются. Просмотри результат и попроси нужные изменения — Codex обновит тот же макет.

Над формой находятся две иконки с подсказками **«Скачать»** и **«Скопировать»**. В каждом подменю можно выбрать **HTML**, **MD** или **PNG**. HTML — самостоятельная интерактивная страница с текущими значениями полей и выбранными вкладками, MD — актуальный исходник макета, PNG — изображение отображаемой формы без кнопок экспорта. Копирование зависит от разрешения браузера на доступ к буферу обмена; при отказе рядом с иконками появится сообщение.

Исходник хранится до остановки сервера. Ввод в браузере сбрасывается при перезагрузке или обновлении исходника. Команды макета не выполняют операции в 1С. Когда результат готов, выбери нужный формат и скачай или скопируй его.

Если предпросмотр перестал открываться, попроси Codex запустить его заново.

## Обновление и удаление

Для обновления отправь Codex:

```text
Обнови магазин ShadobaAI командой:
codex plugin marketplace upgrade shadobaai
```

Дождись успешного обновления, перезапусти приложение и начни новый чат. Команда описана в [справочнике Codex CLI](https://learn.chatgpt.com/docs/cli/reference#codex-plugin-marketplace).

Для удаления попроси Codex остановить предпросмотры, затем удали **Накидку** в разделе **Плагины**. Файлы, которые ты скачал, останутся у тебя.

## Для разработчика

Нужны Git, Node.js 22+ с npm и Python 3.12+. Клонируй репозиторий и выполни:

```powershell
git clone https://github.com/ShadobaAI/md_design.git
cd md_design
npm.cmd ci
npm.cmd run build
npm.cmd test
python -m unittest discover -s tests -p "test_*.py"
```

В macOS/Linux используй `npm` вместо `npm.cmd`.

Проверка и открытие формы:

```powershell
node scripts/preview.mjs --file prototypes/order.md --check
node scripts/preview.mjs --file prototypes/order.md --background
```

Новые макеты передавай через UTF-8 стандартный ввод без сохранения файла:

```powershell
$OutputEncoding = [System.Text.UTF8Encoding]::new($false)
@'
--- Новая форма ---
Номер: 123
'@ | node scripts/preview.mjs --stdin --name "form.md" --background
```

Для проверки используй `--check` вместо `--background`; для правок передай полный новый исходник с `--stdin --update "<url предпросмотра>"`. `--name` задаёт имя экспорта, файл на диске не создаётся.

Открой полный `url` из ответа. Для остановки используй возвращённый `pid`. При запуске из песочницы Codex в Windows см. [разрешения запуска](skills/md-design/references/runtime.md#windows-sandbox).

Локальный пакет для проверки установки:

```powershell
npm.cmd run package:plugin -- --version 0.1.0
npm.cmd run check:plugin
```

ZIP-файлы и `SHA256SUMS` появятся в `.build`, каталог для проверки установки — в `.build/marketplace`. Для локальной проверки подключай этот каталог, а не репозиторий исходников; [инструкция OpenAI](https://developers.openai.com/plugins/build/plugins#add-a-marketplace-from-the-cli). Шаблон каталога: [packaging/marketplace.template.json](packaging/marketplace.template.json).

Для выпуска:

1. В настройках Actions репозитория `ShadobaAI/md_design` добавь secret `MARKETPLACE_TOKEN`: fine-grained GitHub token с доступом только к `ShadobaAI/codex-plugins` и правом **Contents: Read and write**. Ветка `main` магазина должна разрешать push владельцу токена.
2. Отправь проверенные исходники в `main`.
3. Создай тег свободной версии в формате `MAJOR.MINOR.PATCH`, без префикса `v`, и отправь его:

   ```powershell
   git tag 0.1.0
   git push origin 0.1.0
   ```

4. Дождись успешных **Build md-design plugin** и **Publish md-design to codex-plugins** в Actions. При сбое публикации повтори её workflow с `build_run_id` успешной сборки тега.

CI проверяет pull request и стабильные теги; обычный push ветки сборку не запускает. Версия релиза берётся из тега. Готовый плагин публикуется в `plugins/md-design` репозитория `ShadobaAI/codex-plugins`.
