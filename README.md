# Накидка — прототипы форм 1С

Основано на **[основном проекте md_design — crimsongoldteam/md_design](https://github.com/crimsongoldteam/md_design)**. Этот репозиторий добавляет скилл Codex и интерактивный просмотр форм; исходная библиотека включена с сохранением лицензии.

Скилл Codex и локальная интерактивная визуализация — один устанавливаемый инструмент. Опиши форму словами, приложи скриншот или XML: Codex создаст/изменит `.md` и откроет форму во встроенном браузере. В браузере **только форма**, без редактора и служебных кнопок. Ввод данных, флажки, переключатели, вкладки, меню и ячейки таблиц работают локально; данные не сохраняются, бизнес-команды 1С не исполняются.

## Установка с нуля: Windows

Программировать не нужно. Один раз установи вспомогательную программу и выполни одну команду. Дальше работай обычными сообщениями в приложении **Codex**.

**Что понадобится:** установленный Codex и подключение к интернету на время установки. Как скачать инструмент, описано в шаге 1 ниже. База 1С, EDT, Git и редактор кода для просмотра макетов не нужны.

### 1. Получи папку с инструментом

Если папка уже есть, пропусти скачивание. На твоём компьютере она может находиться, например, здесь: `C:\md_design`.

Если тебе дали ZIP-архив проекта, нажми на него правой кнопкой мыши → **Извлечь всё**. Затем открой распакованную папку с файлами инструмента. Не запускай установку прямо из архива.

Если скачиваешь инструмент из [этого репозитория на GitHub](https://github.com/ShadobaAI/md_design), нажми **Code → Download ZIP**, распакуй архив и открой папку `md_design-main`. В ней должны быть файлы `package.json`, `package-lock.json` и этот `README.md`. Для удобства можешь переименовать папку в `md_design` и переместить её в `C:\md_design`.

### 2. Установи Node.js

**Node.js** — программа, которая запускает визуализатор. Вместе с ней устанавливается **npm** — помощник для установки необходимых компонентов.

1. Открой [официальный сайт Node.js](https://nodejs.org/en/download).
2. Выбери **LTS**, **Windows** и установщик **Windows Installer (.msi)**. Подходит версия 22 или новее. Для обычного компьютера с процессором Intel/AMD выбирай `x64`; для Windows на ARM — `ARM64`.
3. Запусти скачанный установщик. Оставь стандартные настройки, включая npm и добавление в PATH — это позволит Windows находить программу. Дойди до **Finish**. Дополнительные инструменты для компиляции устанавливать не требуется.
4. Закрой ранее открытые окна терминала и полностью перезапусти Codex, чтобы они увидели установленную программу.

Если Node.js уже установлен, повторная установка может не понадобиться: проверь версию на следующем шаге.

### 3. Открой окно для команд в нужной папке

1. Открой папку `md_design` в Проводнике Windows.
2. Щёлкни по адресной строке сверху — там, где написан путь к папке.
3. Вместо пути напиши `powershell` и нажми **Enter**.

Откроется окно с текстом — это **PowerShell**. Оно позволяет дать компьютеру команду. Запускать его от имени администратора для установки скилла не нужно.

Вставь следующую строку и нажми **Enter**:

```powershell
node --version
```

Ожидаемый ответ выглядит как `v24.18.0`; число после `v` должно быть **22 или больше**. Если написано, что `node` не найден, смотри раздел «Если что-то пошло не так» ниже.

### 4. Установи инструмент

В том же окне вставь строку и нажми **Enter**:

```powershell
npm.cmd run setup
```

`npm.cmd` — вариант команды npm для Windows. Он работает и там, где PowerShell запрещает запуск файла `npm.ps1`; менять настройки безопасности Windows не нужно.

Дождись завершения. Во время установки в окне будет много текста — это нормально. Команда сама скачает необходимые компоненты, подготовит визуализатор и положит скилл туда, где Codex его найдёт.

**Признак успешной установки:** в конце появится строка со словом `installed` и путём, похожим на:

```text
C:\Users\ТвоёИмя\.agents\skills\md-design
```

Имя пользователя будет твоим; двойные обратные слеши в напечатанной строке тоже нормальны. Если вместо этого появилась ошибка, не считай установку завершённой — решения ниже. После успешной установки окно PowerShell можно закрыть.

### 5. Проверь в Codex

1. Полностью закрой Codex и открой его снова.
2. Открой рабочую папку, где хочешь хранить прототипы. Для этого можно заранее создать обычную папку «Прототипы форм» в Документах.
3. Создай задачу и отправь сообщение:

```text
$md-design Создай форму поступления: номер, дата, контрагент, склад
и таблица с товаром, количеством и ценой. Открой форму во встроенном браузере.
```

**Ожидаемый результат:** Codex создаст текстовый файл с описанием формы и откроет рядом визуализацию. В ней можно вводить значения, переключать флажки и вкладки, раскрывать меню. Редактора кода и служебных кнопок в форме нет.

Если Codex запросит разрешение запустить локальный предпросмотр или записать файл в рабочую папку, проверь, что запрос относится к этому инструменту, и разреши действие. Это обычные ограничения доступа приложения; они зависят от твоих настроек.

### Если что-то пошло не так

| Что видишь | Что сделать |
| --- | --- |
| `node` или `npm.cmd` не распознаны | Установи Node.js, затем закрой и заново открой PowerShell. Если не помогло, повторно запусти установщик Node.js со стандартными настройками PATH и npm. |
| Версия Node.js ниже 22 | Установи свежую LTS-версию с официального сайта. |
| `npm.ps1 ... выполнение сценариев отключено` | Используй именно `npm.cmd run setup`, не меняй политику выполнения PowerShell. |
| `ENOENT`, упоминание `package.json` или `Missing script: setup` | Команда запущена не из той папки. Закрой окно, открой `md_design` с файлом `package.json` и повтори шаг 3. |
| `Каталог уже существует` | Скилл уже установлен. Для обновления используй инструкцию ниже. |
| `ETIMEDOUT`, `ENOTFOUND`, `ECONNRESET` или ошибка сертификата | Проверь интернет. В рабочей сети установка может требовать помощи системного администратора. Не отключай проверку сертификатов. |
| Ошибка доступа к папке | Скопируй проект в свою папку, например «Документы», и повтори. В управляемом компьютере обратись к администратору с полным текстом ошибки. |
| Codex не видит `$md-design` | Перезапусти приложение и создай новую задачу. Проверь, что шаг 4 завершился строкой `installed`. |
| Форма перестала открываться | Попроси Codex: «Заново запусти предпросмотр этого прототипа и открой его». Локальная ссылка работает, пока запущен её процесс. |

Для другой ошибки скопируй её текст и отправь Codex вместе с сообщением «Помоги закончить установку md_design». Не нужно разбираться в содержимом сотен файлов или исправлять их вручную.

## Универсальный пример

Чтобы посмотреть возможности инструмента без подготовки своей формы, отправь Codex:

```text
$md-design Открой универсальный пример showcase во встроенном браузере.
```

В нём шесть вкладок с полями, флажками, группами, меню, таблицами и оформлением. Можно вводить данные, раскрывать меню, переключать вкладки и выбирать цвета. [Файл примера](prototypes/showcase.md), [перечень возможностей и отличий](references/showcase.md).

## Как пользоваться после установки

Пиши Codex обычными словами; `$md-design` помогает явно выбрать этот инструмент.

- **По описанию:** «Создай форму карточки контрагента с контактами и вкладкой Договоры».
- **По скриншоту:** приложи изображение и напиши «Повтори эту форму в md_design и открой в браузере».
- **По XML:** приложи файл формы и напиши «Восстанови интерфейс из XML, сохрани группы и вкладки».
- **Изменение:** «В этот прототип добавь поле Телефон после поля Наименование».

Codex сам сохраняет описание в файл `.md` в твоей рабочей папке, запускает просмотр и открывает встроенный браузер. Запускать команды вручную каждый раз не нужно. После установки визуализатор работает без интернета; самому Codex интернет по-прежнему может быть нужен.

Ввод в браузере **не сохраняется**: после перезагрузки вернутся значения из описания. Чтобы изменить прототип надолго, попроси Codex изменить файл `.md`. Кнопки команд показывают интерфейс, но не записывают данные в базу и не выполняют операции 1С.

## Обновление

Получи свежую папку проекта. Открой PowerShell в её папке `md_design`, как в шаге 3. Выполняй строки по одной; переходи к следующей только после успешного завершения предыдущей:

```powershell
npm.cmd ci
npm.cmd run build
node scripts/install.mjs --replace
```

Последняя команда сохранит предыдущую установленную версию в резервной папке `md-design.backup-<дата-в-миллисекундах>`. В резервной копии файл скилла называется `SKILL.md.backup`, чтобы Codex не подключил его второй раз. Твои прототипы в рабочих папках останутся на месте. После обновления перезапусти Codex.

## Удаление

Сначала попроси Codex остановить предпросмотры, которые он запустил для md_design. Затем нажми **Win + R**, вставь `%USERPROFILE%\.agents\skills` и нажми **Enter**. Удали внутри только папку `md-design` и перезапусти Codex. Файлы прототипов в рабочих папках этим не удаляются.

## Технические сведения

Дальнейшие разделы нужны для разработки и диагностики. Для обычного использования предыдущих шагов достаточно.

Другой каталог установки задаётся командой `node scripts/install.mjs --destination <путь>`, например `<проект>/.agents/skills/md-design`. Не устанавливай две копии с одинаковым именем в областях обнаружения одного проекта. [Официальная документация о расположении скиллов Codex](https://learn.chatgpt.com/docs/build-skills).

Ручной запуск из папки исходников:

```powershell
node scripts/preview.mjs --file prototypes/order.md --check
node scripts/preview.mjs --file prototypes/order.md --background
```

Запуск возвращает JSON: `url`, `pid`, `file`. Используй URL целиком, включая случайный сегмент пути. Сервер слушает только `127.0.0.1` и отдаёт один выбранный файл и три статических ресурса; произвольных путей, удалённых URL, записи через HTTP и CORS нет. Файл перечитывается примерно раз в секунду; форма перерисовывается только при изменении текста.

## Что входит в пакет

Устанавливаются SKILL.md, справочники, два runtime-скрипта, собранные JS/CSS/HTML, примеры и лицензии. `node_modules`, TypeScript, тесты и исходники upstream пользователю для работы **не нужны**.

В репозитории сохранена минимальная транзитивная часть исходников парсера [md_design](https://github.com/crimsongoldteam/md_design), а не полный upstream-проект. Точный commit и список файлов — `vendor/UPSTREAM.json`, лицензия MIT — `vendor/md_design/LICENSE.md`. Собственные файлы не требуют изменения стороннего репозитория или абсолютного пути к локальной копии. Лицензии фактически включённых npm-компонентов собираются в `dist/THIRD_PARTY.md`.

## Границы точности

Стиль полей и кнопок основан на upstream `index.css` с компактными размерами и жёлтыми акцентами 1С. Браузерная компоновка не воспроизводит платформенный движок 1С побитно. Основные группы, страницы, поля, флажки, переключатели, меню, простые таблицы, дерево строк и составные заголовки поддерживаются. Всплывающие группы представлены раскрываемыми секциями; библиотека картинок, произвольное оформление и обработчики 1С не эмулируются. Окна выбора значений локальные, без доступа к справочникам.

Неподдержанные свойства доступны Codex в `#preview[data-warnings]`; непонятный элемент отображается явным заполнителем. Ошибка разбора/загрузки видна на странице, устаревшая форма при ошибке скрывается. Скилл требует сообщать существенные отличия от скриншота/XML и не ограничивает XML закрытым перечнем тегов. Подробнее: [разметка](references/syntax.md), [восстановление](references/reconstruction.md).

Адаптер проверяет ошибки lexer/parser, нормализует CRLF/BOM и расширяет текстовый токен для кавычек/типографской пунктуации. Исходный upstream может терять эти символы. Hex-цвета внутри свойств также поддерживаются адаптером. Структурные разделители DSL сохраняют своё значение; универсального экранирования в языке нет.

## Проверки и разработка

```powershell
npm ci
npm run build
npm test
npm audit
```

Тесты проверяют разбор и вывод элементов, интерактивные состояния, безопасное отображение текста, ограничения HTTP и установку готового пакета. Для обновления upstream меняй закреплённый snapshot осознанно и проверяй весь этот набор. Runtime не использует Vite dev server, Monaco или поисковые/AI-сервисы. Сборка — esbuild, исходники — TypeScript, runtime — стандартная библиотека Node.js.
